# gokturkscoolrepo
Windows Admin Panel (Batch)

A simple Windows Administrator Panel written in Batch (.bat).
This project provides a basic menu-driven interface for executing common Windows administrative and system commands.

Description

This script is designed for educational and practical use.
It helps users perform basic administrative tasks through a single command-line menu instead of typing commands manually.

Features

Menu-based interface

Written entirely in Batch (.bat)

No external tools or dependencies

Fast and lightweight

Easy to edit and extend

Suitable for beginners learning Windows scripting

Requirements

Windows 7 / 8 / 10 / 11

Command Prompt (cmd.exe)

Administrator privileges (recommended)

How to Use

Download or clone the repository:

git clone https://github.com/gokturkk-hub/gokturkscoolrepo.git


no need to open it on admin its doing it byself on start

Select an option from the menu.

Example Use Cases

Display system information

Run network-related commands

Access Windows management tools

Perform quick admin tasks

Customization

You can easily modify the script:

Add new menu options

Change commands

Improve visuals (colors, titles)

Add security checks
